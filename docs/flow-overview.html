Dây chuyền reup: xóa sub ∥ lồng tiếng Việt

Một click trên trang video — extension nhặt file + toàn bộ metadata đẩy lên Drive/Sheet; container GPU xóa hardsub và lồng tiếng Việt cùng lúc trên cùng một video, ghép lại rồi trả link thành phẩm về Sheet. Máy chỉ bật khi có việc.

~1.200⚡mỗi video 10 phút (RTX 3090, đã gồm cả 2 bước)
10–12 phútmáy chạy cho video 10 phút — dub "trốn" trong lúc xóa sub
2 việc · 1 GPUVSR ~2GB + VoiceStudio ~6–8GB, vừa vặn VRAM 24GB
1 clickextension nhặt video + metadata — phần sau tự động 100%

Toàn luồng xử lý

Ba khu vực: việc của bạn, kho trung gian trên cloud (sống sót kể cả khi xóa container), và container GPU thuê theo giờ.

Ingest: extension tự viết là cổng vào duy nhất

Không có nguồn public → không có yt-dlp trong hệ thống. Cookies + IP datacenter dính risk-control Douyin, còn session đăng nhập thật trong browser là trình tải đáng tin nhất — và metadata (title, thumbnail, description, author) nằm sẵn trong DOM. Worker chỉ đọc một hợp đồng dữ liệu, không biết nguồn video là gì.

Khi extension hỏng. Ghi đúng cùng hợp đồng → toàn bộ phần xử lý phía sau vẫn tự động.

Kết luận:

Worker lõi là đúng một quy trình xử lý video (Drive vào → Drive ra), không chứa bất kỳ logic ingest nào. Mọi coupling với trang nguồn dồn hết về extension.

Stack & quy trình code

Extension : TypeScript — Manifest V3, build Vite · chạy trên Chrome máy local
Worker    : Python 3.12 (uv) — gọi VSR CLI · VoiceStudio REST · gspread · rclone
Hợp đồng  : JSON Schema — extension sinh TS types, worker validate bằng pydantic
Code flow : local (Claude Code) → push GitHub private → container git clone + ./setup.sh lần đầu, git pull + restart các lần sau · secrets scp 1 lần, không commit

Container chỉ là nơi chạy — code luôn ở local + GitHub, xóa máy thuê không mất gì. Extension dev hoàn toàn ở local (Load unpacked), không liên quan container.

Lộ trình

Extension lên trước — nó chỉ phụ thuộc hợp đồng ingest, không phụ thuộc worker. Spike VoiceStudio tranh thủ chạy lúc container đang bật sẵn.

PHASE 1

Nơi lưu trước: Drive + Sheet + hợp đồng TIẾP THEO

Tạo Drive thật (inbox/ mỗi video 1 folder · output/), Sheet thật đủ cột + dòng mẫu, service account share quyền. Rồi mới văn bản hóa thành meta.schema.json + sheet-columns.md trong repo GitHub private. Hợp đồng v1 chốt → hai phía code theo nó.

PHASE 2

Extension ingest (TypeScript, Manifest V3)

Nút 1-click trên trang video: bắt file + title/description/tags/author + thumbnail, up Drive (resumable qua chrome.identity), ghi Sheet theo hợp đồng. Deliverable: click → mọi thứ nằm đúng chỗ trên Drive + dòng NEW trong Sheet.

PHASE 3

Spike VoiceStudio + worker lõi (Python)

Cài VoiceStudio headless, dub thử 1.mp4 sang tiếng Việt — đo thời gian/VRAM/chất lượng, chốt thuê 3090. Worker CLI: song song VSR ∥ dub → mux. Đúng 1 quy trình xử lý, không chứa logic ingest.

PHASE 4

Nối vòng: Sheet + Drive + Telegram

Service account, worker poll Sheet, rclone 2 chiều, bot thông báo, setup.sh hoàn chỉnh. Deliverable: click extension → thành phẩm tự về Drive, không đụng terminal.

PHASE 5

Tối ưu & tiện ích

Pipeline nhiều video đồng thời, retry, log chi phí ⚡/video · sinh title/description/tags tiếng Việt bằng LLM từ metadata gốc · cân nhắc auto-upload (YouTube API app chưa verify sẽ khóa video ở private).
